# 设计参考

Mayf3 使用 React Aria Components 提供键盘、焦点和弹层行为，以语义 Token、CSS 和本地图标实现视觉层。以下项目提供了设计参考。

- [Untitled UI React](https://github.com/untitleduico/react) 和 [Coss UI](https://github.com/cosscom/ui) 展示控件比例、按压反馈、输入错误及浮层边界。
- [Beautiful UI](https://github.com/slev12397/beautiful-ui) 展示任务行、工具摘要、交付结果和人工审批的编排方式。
- [Intent UI](https://github.com/irsyadadl/intentui) 和 [Motion Primitives](https://github.com/ibelick/motion-primitives) 展示状态样式与行为的分工，以及选中底板的连续性。
- [Magic UI](https://github.com/magicuidesign/magicui) 和 [Paper Shaders](https://github.com/paper-design/shaders) 展示表面边缘、阴影分层和局部漫射光。工作台用静态 CSS 表现相关材质。

工作台采用自有组件组合、示例数据和图标。运行与开发依赖见各工作区的包清单和根锁文件。
