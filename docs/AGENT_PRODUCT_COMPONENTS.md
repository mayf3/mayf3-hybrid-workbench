# Mayf3 Agent 产品组件

本组组件供 Storybook Premium 工作台使用。八项接口在预览中复用现有 Foundation 的 Button、StatusBadge、Dialog、Tabs、SelectField 和 React Aria 表单适配。业务层持有状态和决定，视图以类型化属性呈现结果。预览保存在浏览器内存，在冷启动时载入同一份任务、证据和状态数据。

## 数据约定

- Domain 类型在 [agent-model.ts](../workbench/stories/premium-agent/agent-model.ts)。样例协调模型在 [AgentWorkspaceModel.tsx](../workbench/stories/premium-agent/AgentWorkspaceModel.tsx)。状态更新以实体 ID 寻址，并把同一次变更关联到相关任务、审批、差异、交付与时间线。
- 视图接受已经脱敏、面向工作区的展示字段。工具输入与结果均为业务摘要。任务执行描述只来自可公开阶段与可观测更新。
- 风险等级与处理结果是不同字段。审批注明决定要作用到哪个资源或差异，谁应处理，接受或者拒绝会有什么后果。
- 发布真实产品适配时，由产品提供权限、可重试语义、持久化和实际时间。当前工作台在本地模拟这些用例，任务、审批、附件和工具结果均为预览记录。

## AgentTaskRow

| 项目 | 约定 |
| --- | --- |
| 场景与 API | 任务表内的单行。接收 `task: AgentTask`、`onAction(id, action)`。任务包含 ID、任务名、负责人、状态、0–100 的进度、更新时间、人工介入标记和公开阶段。 |
| 状态模型 | 队列可开始，运行中可暂停，正常暂停可继续。待人工处理的任务在解除对应审批边界前保持其干预状态。非法或重复转换由工作台协调模型忽略。 |
| 视觉 Token | 标题使用标签排版角色，负责人和时间使用次级前景，状态文字、图标与进度条使用对应的语义色。数据行只以细分隔线分组。 |
| Accessibility | 原生表格的列头和行头、具名进度值、含任务名的行操作、状态文案和人工介入提示。过滤使用现有 Tabs，搜索支持在任务区内按 Ctrl/⌘+K 聚焦。 |
| 禁止用法 | 禁止以颜色代替状态文案，把每条任务变为独立大卡片，或从进度百分比推断审批完成。 |
| 验收 | 暂停和继续可操作且进度保留，待确认筛选与审批结果同步，390px 下长名称可换行且状态、进度与时间可读。 |

## AgentApprovalCard

| 项目 | 约定 |
| --- | --- |
| 场景与 API | 人工审批等待区。接收 `approval: AgentApproval`、`onDecision(id, approved \| rejected)`。数据包括申请人、责任人、风险、作用范围、可能后果和关联任务 ID。 |
| 状态模型 | 单个请求从 pending 单向进入 approved 或 rejected。高风险批准先通过确认 Dialog。拒绝保留原基线并让关联任务等待负责人处理。 |
| 视觉 Token | 细边界和可见责任人字段承载默认信息密度。高风险用危险语义边缘和风险提示面，低风险用中性色。浮层继承工作区 Overlay 层级。 |
| Accessibility | 卡片以请求标题命名。风险、后果和责任人是可读文本。确认框默认聚焦取消，并由 Dialog 管理按键、焦点范围和恢复。 |
| 禁止用法 | 禁止隐藏可能后果或相关责任人，将高后果直接绑定至一键批准，或用显示样式模拟权限核验。 |
| 验收 | 低风险直接批准、高风险确认与取消、拒绝、结果宣布、任务与差异联动、按 Escape 关闭详情及焦点恢复。 |

## AgentToolCall

| 项目 | 约定 |
| --- | --- |
| 场景与 API | 工具证据记录。接收 `call: ToolCall` 和 `onRetry(id)`。记录具有名称、稳定命令标识、调用方、输入摘要、结果、错误摘要和尝试次数。 |
| 状态模型 | 通过或失败。展开信息只读，失败时可发起一次本地重试。从失败恢复后更新结果和次数，原失败继续保留在时间线。 |
| 视觉 Token | 工具标识采用 Mono 和浅色状态面。失败使用危险文字，结果与输入共享普通文本角色。 |
| Accessibility | 原生 disclosure 处理 Enter、Space 和展开语义。失败、重试和通过为显式文本。重试后焦点返回本条调用摘要。 |
| 禁止用法 | 禁止把密钥、原始系统日志、未经脱敏的输入或未归一化的异常对象直接呈现。 |
| 验收 | 键盘展开失败记录，查看错误与结果，重试后通过且出现恢复事件。 |

## AgentThinkingState

| 项目 | 约定 |
| --- | --- |
| 场景与 API | 运行总览中的当前任务。接收 `task: AgentTask`，读取任务名称、状态、负责人、进度、公开阶段和公开更新。 |
| 状态模型 | 显示随业务状态变化的可公开阶段和确定的进度。执行暂停期间文案与进度保持一致。 |
| 视觉 Token | 特色表面承载主要执行焦点，低饱和 Material 与语义状态色并用，使用等宽数值。 |
| Accessibility | 可命名的进度条、状态文字、独立的状态更新 live region。阶段与进度在减弱动效下持续可读。 |
| 禁止用法 | 禁止展示模型私有推理链、内部令牌、系统提示、未公开草稿或模拟逐字推理。 |
| 验收 | 三种视觉方向共享同一公开数据，暂停可见，移动和 Reduced Motion 下可扫读。 |

## AgentActivityTimeline

| 项目 | 约定 |
| --- | --- |
| 场景与 API | 可审阅的工作记录。接收 `events: readonly AgentEvent[]`，由调用方按时间倒序提供，含稳定 ID、时间、参与者、状态种类和事件标题。 |
| 状态模型 | 执行、等待、失败、恢复、交付、排队和暂停为独立事件。重试成功不覆盖此前失败。 |
| 视觉 Token | 细线、紧凑图标槽和状态语义文字，时间用 Mono 或等宽数字。 |
| Accessibility | 具名有序列表、`time` 元素与可见事件类型。LTR 时间在 RTL 文档中保持数字顺序。 |
| 禁止用法 | 禁止把错误和恢复合并成无来源的成功，或仅用视觉顺序表达时间先后。 |
| 验收 | 最新状态可定位，事件按倒序呈现，失败与恢复信息同时可见，长事件在 390px 下换行。 |

## AgentDiffTable

| 项目 | 约定 |
| --- | --- |
| 场景与 API | 审批和交付间的变更记录。接收 `changes: readonly AgentChange[]`，含变更名、原值、候选值、影响范围与审批状态。 |
| 状态模型 | 差异行反映对应审批的待审批、已批准或已拒绝。批准改变决定状态，预览记录不写入实际资源。 |
| 视觉 Token | 紧凑语义表格、轻量标记区分原值和新值，审批结果映射状态角色。 |
| Accessibility | 列头和行头明确读表关系。前后标签和状态文字自行表达含义。 |
| 禁止用法 | 禁止把纯外观差异等同于验收通过，或以红绿颜色默示操作成功。 |
| 验收 | 原值、候选值、影响范围都可扫描，审批与对应差异记录联动。 |

## AgentDeliverySummary

| 项目 | 约定 |
| --- | --- |
| 场景与 API | 阶段验收与交接。接收 `delivery: DeliverySummary`，包含完成项、核验结果、证据链接、未解风险和下一责任人。 |
| 状态模型 | 完成项与核验互相独立。校验成功可更新结果，仍留存当前未解决风险和负责角色。 |
| 视觉 Token | 使用普通内容层和可辨识链接色。未解决风险使用警示语义状态。 |
| Accessibility | 术语列表、具名证据链接与可读的责任人。跳转目标使用工作区区块 ID。 |
| 禁止用法 | 禁止仅凭执行成功宣布验收通过，或省略证据与下一责任人。 |
| 验收 | 两条证据链接各自可跳转，快照索引重试时只更新相关验收结果，风险仍可见。 |

## AgentPromptBar

| 项目 | 约定 |
| --- | --- |
| 场景与 API | 从工作区发起任务。接收 `onSubmit(TaskPrompt)`，输入含任务意图、显式上下文、执行方式及可选的本地附件文件名。 |
| 状态模型 | 空白不可提交。成功发起后进入本地队列，输入清空并回焦，确认可被读屏宣布。附件仅作为可移除的文件名上下文。 |
| 视觉 Token | 默认面承载一组清晰分区的表单，输入焦点、按钮层级和 Portal 沿用基础控件。 |
| Accessibility | 可见字段标签，Enter 保留换行，Ctrl/⌘+Enter 提交，中文输入法组合期间保留正常键入。附件、模式与提交均可用键盘操作。 |
| 禁止用法 | 禁止使用输入框代替任务范围和方式的显式选择，或者让本地附件选择偷偷上传内容。 |
| 验收 | 空白和长内容、换行与快捷提交、上下文和运行方式选择、移除附件、队列与活动同步以及提交后回焦。 |
